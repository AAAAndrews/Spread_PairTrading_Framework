# 回归信号生成快速指南

## 🚀 快速开始

### 1. 固定阈值模式（简单）

```python
from src.core.ml_models import SignalGenerator

# 创建信号生成器：预测收益率超过±3%时开仓
signal_generator = SignalGenerator(
    model,                              # 你的回归模型
    regression_upper_threshold=0.03,    # 做多阈值: +3%
    regression_lower_threshold=-0.03,   # 做空阈值: -3%
    use_rolling_quantile=False,         # 固定阈值
    signal_holding_days=10
)

# 生成信号
signals = signal_generator.generate_signals(X_test)
```

### 2. 滚动分位数模式（推荐）

```python
# 创建信号生成器：使用动态分位数阈值
signal_generator = SignalGenerator(
    model,
    use_rolling_quantile=True,      # ✅ 滚动分位数
    rolling_window=60,               # 60天窗口
    upper_quantile=0.75,             # 75%分位数
    lower_quantile=0.25,             # 25%分位数
    signal_holding_days=20
)

signals = signal_generator.generate_signals(X_test)
```

## 📊 信号含义

| 信号值 | 含义 | 条件 |
|-------|------|------|
| 1 | 做多 | 预测值 > 上阈值 |
| 0 | 观望 | 下阈值 ≤ 预测值 ≤ 上阈值 |
| -1 | 做空 | 预测值 < 下阈值 |

## 🎯 参数选择建议

### 滚动窗口（rolling_window）
- **日线数据**: 40-80天（2-4个月）
- **周线数据**: 12-26周（3-6个月）

### 分位数配置

| 风格 | upper_quantile | lower_quantile | 信号频率 |
|-----|---------------|---------------|---------|
| 保守 | 0.80 | 0.20 | 低（~20%） |
| 标准 | 0.75 | 0.25 | 中（~25%） |
| 激进 | 0.70 | 0.30 | 高（~30%） |

## ⚠️ 重要提示

1. **回归目标应该是收益率**，不是价格
   ```python
   # ✅ 正确：预测未来收益率
   target = (price[t+20] - price[t]) / price[t]
   
   # ❌ 错误：预测未来价格
   target = price[t+20]
   ```

2. **信号维持天数应该匹配预测窗口**
   ```python
   # 预测未来20天收益 → 信号维持20天
   signal_holding_days = 20
   ```

3. **优先使用滚动分位数**
   - 自适应市场变化
   - 避免固定阈值失效
   - 自动平衡信号频率

## 📈 完整示例

```python
# 训练回归模型
model = MLModel(model_type='gradient_boosting', task='regression')
model.train(X_train, y_train)

# 生成信号（滚动分位数）
signal_gen = SignalGenerator(
    model,
    use_rolling_quantile=True,
    rolling_window=60,
    upper_quantile=0.75,
    lower_quantile=0.25,
    signal_holding_days=20
)
signals = signal_gen.generate_signals(X_test)

# 回测
backtest_engine = BacktestEngine(
    initial_capital=1000000,
    max_position=10000,
    leverage=10.0
)
equity_curve = backtest_engine.run_backtest(price_data, signals)
```
