### ✅ 问题2：带时区datetime的转换错误

**错误信息**：
```
ValueError: Tz-aware datetime.datetime cannot be converted to datetime64 unless utc=True
```

**根本原因**：
当源数据的 datetime 已经带有时区信息时，`pd.to_datetime()` 需要指定 `utc=True` 参数

**修复方案**：
```python
# ✅ 正确代码
macro_df['date'] = pd.to_datetime(macro_df['date'], utc=True)  # 添加utc=True参数
if hasattr(macro_df['date'].dtype, 'tz') and macro_df['date'].dtype.tz is not None:
    macro_df['date'] = macro_df['date'].dt.tz_localize(None)  # 然后移除时区
```

**修复位置**：
- `debug_strategy.py` 第292行
- `main.py` 第222行

### ✅ 问题3：时区不兼容导致join失败

**错误信息**：
```
TypeError: Cannot join tz-naive with tz-aware DatetimeIndex
```

**根本原因**：
不同 DataFrame 的索引有些带时区（tz-aware），有些不带时区（tz-naive），pandas 不允许混合时区的 DataFrame 进行 join

**修复方案**：
```python
# ✅ 在合并前统一清理所有DataFrame的索引时区
for i, df in enumerate(all_features):
    if hasattr(df.index, 'tz') and df.index.tz is not None:
        all_features[i].index = df.index.tz_localize(None)
```

**修复位置**：
- `debug_strategy.py` 第355-362行
- `main.py` 第258-263行

### ✅ 问题4：列名重复导致merge失败

**错误信息**：
```
ValueError: columns overlap but no suffix specified: 
Index(['spread', 'spread_name', 'spread_mean', 'spread_std', ...])
```

**根本原因**：
`macro_features` 通过 `reset_index()` 从 `main_spread` 创建时，保留了所有原始列（包括 spread 相关列），导致与 `spread_features` 的列名重复

**修复方案**：
```python
# ✅ 只保留宏观数据列，去除来自main_spread的列
macro_cols = [col for col in macro_features.columns if any(x in col for x in ['VIX', 'DXY'])]
macro_features = macro_features[macro_cols]
```

**修复位置**：
- `debug_strategy.py` 第318-319行
