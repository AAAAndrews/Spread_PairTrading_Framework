# 止损功能 - 快速参考

## 🎯 核心参数

```python
BacktestEngine(
    stop_loss_pct=0.05,      # 百分比止损（5%）
    stop_loss_amount=10000   # 金额止损（$10000）
)
```

---

## 📊 止损类型

| 类型 | 参数 | 触发条件 | 示例 |
|------|------|---------|------|
| **百分比** | `stop_loss_pct` | 亏损 ≥ 设定百分比 | 5%止损，价格跌5%触发 |
| **金额** | `stop_loss_amount` | 亏损 ≥ 设定金额 | $10000止损，亏$10000触发 |
| **混合** | 两者都设置 | 先触发哪个执行哪个 | 5%或$10000，先到先止 |

---

## 💻 快速使用

### 1. 基本用法

```python
# 创建回测引擎（带止损）
engine = BacktestEngine(
    initial_capital=1000000,
    stop_loss_pct=0.05,      # 5%止损
    stop_loss_amount=10000   # $10000止损
)

# 运行回测
equity_curve = engine.run_backtest(prices, signals)
```

### 2. 只用百分比

```python
engine = BacktestEngine(
    stop_loss_pct=0.03,      # 3%止损
    stop_loss_amount=0       # 不用金额止损
)
```

### 3. 只用金额

```python
engine = BacktestEngine(
    stop_loss_pct=0,         # 不用百分比
    stop_loss_amount=5000    # $5000止损
)
```

### 4. 不用止损

```python
engine = BacktestEngine(
    stop_loss_pct=0,         # 默认
    stop_loss_amount=0       # 默认
)
```

## 📈 参数建议

### 按波动率

| 波动率 | 建议止损 | 资产类型 |
|--------|---------|----------|
| 低 (< 1%) | 2-3% | 债券、外汇 |
| 中 (1-3%) | 3-5% | 股指、贵金属 |
| 高 (> 3%) | 5-10% | 商品期货 |

### 按策略类型

| 策略 | 建议止损 |
|------|---------|
| 高频 | 1-2% |
| 日内 | 2-5% |
| 波段 | 5-10% |
| 长期 | 10-20% |

### 按资金管理

```python
# 单笔风险控制在2%
capital = 1000000
risk_pct = 0.02
stop_loss_amount = capital * risk_pct  # $20,000
```

## ⚡ 工作原理

### 检查时机

```
每个时间步:
1. 检查止损 → 触发？→ 强制平仓
2. 未触发 → 执行正常信号
3. 更新权益
```

### 触发条件

**多头**：
```python
# 百分比
current_price < entry_price × (1 - stop_loss_pct)

# 金额
(entry_price - current_price) × position ≥ stop_loss_amount
```

**空头**：
```python
# 百分比  
current_price > entry_price × (1 + stop_loss_pct)

# 金额
(current_price - entry_price) × |position| ≥ stop_loss_amount
```

## 💡 实战技巧

### 1. 对比测试

```python
configs = [
    {'pct': 0.03, 'label': '3%止损'},
    {'pct': 0.05, 'label': '5%止损'},
    {'pct': 0.10, 'label': '10%止损'},
]

for config in configs:
    engine = BacktestEngine(stop_loss_pct=config['pct'])
    result = engine.run_backtest(prices, signals)
    print(f"{config['label']}: {result['equity'].iloc[-1]:,.2f}")
```

### 2. 动态止损

根据波动率动态调整：

```python
# 高波动期
volatility = prices['close'].pct_change().rolling(20).std()
if volatility.iloc[-1] > 0.03:  # 3%波动
    stop_loss_pct = 0.08  # 宽止损
else:
    stop_loss_pct = 0.03  # 紧止损
```

### 3. 止损 + 仓位

```python
# 紧止损 + 低仓位
engine = BacktestEngine(
    max_capital_usage=0.5,   # 50%资金
    stop_loss_pct=0.03       # 3%止损
)

# 宽止损 + 高仓位
engine = BacktestEngine(
    max_capital_usage=0.8,   # 80%资金
    stop_loss_pct=0.10       # 10%止损
)
```

## ⚠️ 注意事项

### 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 频繁止损 | 止损太紧 | 放宽止损线 |
| 从不触发 | 止损太宽 | 收紧止损线 |
| 亏损仍大 | 止损失效 | 检查参数设置 |

### 成本考虑

```
实际止损成本 = 亏损金额 + 手续费 + 滑点
```

### 心理准备

- 止损是保护机制，不是失败
- 频繁止损说明策略需优化
- 止损后不要立即重新开仓
