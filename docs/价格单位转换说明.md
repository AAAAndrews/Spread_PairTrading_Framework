# 价格单位转换说明文档

## 问题背景

在计算裂解价差（Crack Spread）时，不同能源产品的价格采用不同的计价单位：

| 产品 | 代码 | 原始单位 | 说明 |
|-----|------|---------|------|
| WTI原油 | CL | **美元/桶** | 国际通用单位 |
| RBOB汽油 | RBOB | **美元/加仑** | 北美成品油交易单位 |
| 取暖油/柴油 | HO | **美元/加仑** | 北美成品油交易单位 |

**关键转换关系**：
- 1桶（barrel）= 42加仑（gallons）
- 这是石油行业的标准换算

## 为什么需要单位转换？

### 问题示例

假设我们计算 **3:2:1 裂解价差**：
```
价差 = -3×CL + 2×RBOB + 1×HO
```

#### ❌ 错误计算（不转换单位）

```python
CL = 70 美元/桶
RBOB = 2.5 美元/加仑
HO = 2.3 美元/加仑

价差 = -3×70 + 2×2.5 + 1×2.3
     = -210 + 5.0 + 2.3
     = -202.7  ← 单位不一致，结果无意义！
```

#### ✅ 正确计算（转换单位）

```python
# 转换：所有价格统一为美元/桶
CL = 70 美元/桶
RBOB = 2.5 × 42 = 105 美元/桶
HO = 2.3 × 42 = 96.6 美元/桶

价差 = -3×70 + 2×105 + 1×96.6
     = -210 + 210 + 96.6
     = 96.6 美元/桶  ← 单位一致，结果有意义！
```

## 实现方法

### 1. 在 `SpreadCalculator` 中实现

```python
# src/core/spread_calculator.py

GALLONS_PER_BARREL = 42  # 1桶 = 42加仑

class SpreadCalculator:
    
    @staticmethod
    def convert_units(price: pd.Series, product: str) -> pd.Series:
        """
        将所有产品价格统一转换为美元/桶
        
        Args:
            price: 价格序列
            product: 产品代码
        
        Returns:
            转换后的价格序列（美元/桶）
        """
        if product == 'CL':
            # WTI原油已经是美元/桶，无需转换
            return price
        
        elif product in ['RBOB', 'HO']:
            # RBOB汽油和取暖油从美元/加仑转换为美元/桶
            return price * GALLONS_PER_BARREL
        
        else:
            # 未知产品，不转换但记录警告
            logger.warning(f"未知产品代码 {product}，价格不进行单位转换")
            return price
```

### 2. 在价差计算时自动转换

```python
def calculate_spread(self, spread_name: str, price_data: Dict[str, pd.DataFrame],
                    price_column: str = 'close', convert_to_barrels: bool = True):
    """计算价差序列（自动进行单位转换）"""
    
    for symbol, weight in components:
        # 获取价格
        price = price_data[symbol][price_column].copy()
        
        # 单位转换：统一为美元/桶
        if convert_to_barrels:
            price = self.convert_units(price, symbol)
        
        # 计算加权价格
        weighted_price = price * weight
        component_prices.append(weighted_price)
    
    # 计算价差
    spread = sum(component_prices)
    return spread
```

## 典型的裂解价差值范围

转换单位后，3:2:1 裂解价差的典型范围：

| 市场条件 | 价差范围（美元/桶） | 说明 |
|---------|-------------------|------|
| 正常市场 | 10 - 30 | 炼油利润正常 |
| 高利润 | 30 - 50 | 炼油利润丰厚，适合做多价差 |
| 超高利润 | > 50 | 炼油利润极高，罕见情况 |
| 低利润 | 0 - 10 | 炼油微利，价差可能收窄 |
| 负值 | < 0 | 炼油亏损，适合做空价差 |

**如果价差值在 -200 到 +200 之外，很可能是单位转换出错！**

## 常见错误

### ❌ 错误1：忘记转换单位

```python
# 直接使用原始价格，单位不一致
spread = -3 * cl_price + 2 * rbob_price + 1 * ho_price
# 结果：CL是美元/桶，RBOB和HO是美元/加仑，无法直接相加！
```

### ❌ 错误2：重复转换

```python
# 已经转换过的价格再次转换
rbob_converted = rbob_price * 42
spread = -3 * cl_price + 2 * (rbob_converted * 42)  # ← 重复转换！
```

### ❌ 错误3：使用错误的转换系数

```python
# 1桶 = 42加仑，不是40或50
rbob_barrel = rbob_gallon * 40  # ❌ 错误的系数
```

## 参考资料

### 石油行业标准

- 1桶（barrel）= 42美制加仑（US gallons）
- 1美制加仑 = 3.78541升
- 1桶 ≈ 159升
- 1桶 ≈ 0.159立方米

| 产品类别 | 常用单位 | 交易所 |
|---------|---------|--------|
| 原油 | 美元/桶 | NYMEX, ICE |
| 汽油 | 美元/加仑 | NYMEX |
| 柴油/取暖油 | 美元/加仑 | NYMEX |
| 天然气 | 美元/百万英热单位 | NYMEX |

### 裂解价差类型

| 5:3:2 | -5 CL + 3 RBOB + 2 HO | 更高汽油权重 |

## 总结

**关键要点**：

1. ✅ **单位统一是正确计算的前提**
   - 所有价格必须转换为相同单位（美元/桶）
   
2. ✅ **使用正确的转换系数**
   - 1桶 = 42加仑（行业标准）
   
3. ✅ **自动化转换减少错误**
   - `SpreadCalculator` 自动处理单位转换
   
4. ✅ **验证结果的合理性**
   - 价差值应在合理范围内（通常 -50 到 +100）
   
5. ✅ **记录日志便于排查**
   - 转换过程自动记录日志

遵循这些原则，可以确保裂解价差计算的准确性！
