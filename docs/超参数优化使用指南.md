# 超参数优化使用指南

## 概述

超参数优化模块提供了三种搜索方法来自动寻找机器学习模型的最佳参数：

1. **网格搜索（Grid Search）** - 遍历所有参数组合
2. **随机搜索（Random Search）** - 随机采样参数组合
3. **贝叶斯优化（Bayesian Optimization）** - 智能搜索最优参数

## 快速开始

### 1. 导入模块

```python
from src.core.hyperparameter_tuning import HyperparameterTuner
```

### 2. 创建优化器

```python
tuner = HyperparameterTuner(
    model_type='gradient_boosting',  # 模型类型
    task='classification',            # 任务类型
    scoring='f1_weighted',           # 评分指标
    cv=5,                            # 交叉验证折数
    n_jobs=-1,                       # 并行任务数（-1表示使用所有CPU）
    verbose=1                        # 详细程度
)
```

### 3. 执行搜索

#### 方法1：网格搜索

```python
from sklearn.ensemble import GradientBoostingClassifier

base_model = GradientBoostingClassifier(random_state=42)

best_params = tuner.grid_search(
    model=base_model,
    X_train=X_train,
    y_train=y_train
)
```

#### 方法2：随机搜索

```python
best_params = tuner.random_search(
    model=base_model,
    X_train=X_train,
    y_train=y_train,
    n_iter=50,        # 迭代次数
    random_state=42
)
```

#### 方法3：贝叶斯优化

```python
# 需要先安装: pip install scikit-optimize

best_params = tuner.bayesian_search(
    model=base_model,
    X_train=X_train,
    y_train=y_train,
    n_iter=30,        # 迭代次数
    random_state=42
)
```

### 4. 查看结果

```python
# 最佳参数
print(f"最佳参数: {tuner.best_params_}")

# 最佳得分
print(f"最佳得分: {tuner.best_score_:.4f}")

# 最佳模型
best_model = tuner.best_estimator_

# 搜索结果摘要
summary = tuner.get_search_results_summary()
print(summary.head(10))
```

### 5. 保存结果

```python
tuner.save_results('models/tuning_results')
```

## 选择合适的搜索方法

| 搜索方法 | 优点 | 缺点 | 适用场景 |
|---------|------|------|---------|
| 网格搜索 | • 能找到全局最优<br>• 结果可重现 | • 计算成本高<br>• 参数空间受限 | • 参数空间小<br>• 计算资源充足<br>• 需要全面评估 |
| 随机搜索 | • 计算成本可控<br>• 容易并行化 | • 不保证最优<br>• 可能错过最佳组合 | • 参数空间大<br>• 快速获得好结果<br>• 初步探索 |
| 贝叶斯优化 | • 高效智能<br>• 迭代次数少 | • 实现复杂<br>• 需要额外依赖 | • 参数空间大<br>• 计算成本高<br>• 追求最优性能 |

## 评分指标

### 分类任务

- `accuracy` - 准确率
- `f1` / `f1_weighted` - F1分数
- `precision` / `precision_weighted` - 精确率
- `recall` / `recall_weighted` - 召回率
- `roc_auc` - ROC曲线下面积

### 回归任务

- `neg_mean_squared_error` - 负均方误差
- `neg_mean_absolute_error` - 负平均绝对误差
- `r2` - R²系数

## 最佳实践

1. **先随机搜索，再网格搜索**
   - 用随机搜索快速找到有希望的参数区域
   - 在该区域内用网格搜索精细调优

2. **使用贝叶斯优化节省时间**
   - 当参数空间很大时，贝叶斯优化通常最高效
   - 适合昂贵的训练过程

3. **选择合适的交叉验证折数**
   - 数据量大：cv=3 或 5
   - 数据量小：cv=5 或 10
   - 时间序列：使用TimeSeriesSplit

4. **并行加速**
   - 设置 `n_jobs=-1` 使用所有CPU核心
   - 网格搜索和随机搜索可以完美并行

5. **保存结果**
   - 及时保存搜索结果，避免重复计算
   - 记录搜索历史，便于后续分析

## 故障排除

### 1. 内存不足

```python
# 减少交叉验证折数
tuner = HyperparameterTuner(cv=3)

# 减少迭代次数
tuner.random_search(n_iter=20)
```

### 2. 运行时间太长

```python
# 使用随机搜索代替网格搜索
# 减少参数组合数量
# 增加并行任务数
tuner = HyperparameterTuner(n_jobs=-1)
```

### 3. 结果不稳定

```python
# 设置随机种子
tuner.random_search(random_state=42)

# 增加交叉验证折数
tuner = HyperparameterTuner(cv=10)
```

## 示例：完整工作流

```python
from src.core.hyperparameter_tuning import HyperparameterTuner
from sklearn.ensemble import GradientBoostingClassifier

# 1. 创建优化器
tuner = HyperparameterTuner(
    model_type='gradient_boosting',
    task='classification',
    scoring='f1_weighted',
    cv=5,
    n_jobs=-1
)

# 2. 创建基础模型
base_model = GradientBoostingClassifier(random_state=42)

# 3. 随机搜索（快速探索）
print("步骤1: 随机搜索...")
best_params_random = tuner.random_search(
    model=base_model,
    X_train=X_train,
    y_train=y_train,
    n_iter=50
)

# 4. 在最佳区域进行网格搜索（精细调优）
print("步骤2: 网格搜索...")
refined_grid = {
    'n_estimators': [best_params_random['n_estimators'] - 50,
                     best_params_random['n_estimators'],
                     best_params_random['n_estimators'] + 50],
    'max_depth': [best_params_random['max_depth'] - 1,
                  best_params_random['max_depth'],
                  best_params_random['max_depth'] + 1],
    'learning_rate': [best_params_random['learning_rate'] * 0.5,
                      best_params_random['learning_rate'],
                      best_params_random['learning_rate'] * 1.5]
}

best_params_final = tuner.grid_search(
    model=base_model,
    X_train=X_train,
    y_train=y_train,
    param_grid=refined_grid
)

# 5. 使用最佳参数训练模型
final_model = GradientBoostingClassifier(**best_params_final, random_state=42)
final_model.fit(X_train, y_train)

# 6. 评估和保存
score = final_model.score(X_test, y_test)
print(f"最终模型得分: {score:.4f}")

tuner.save_results('models/tuning_results')
```
