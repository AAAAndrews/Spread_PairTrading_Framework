## 🔍 关键问题诊断与解决

### 问题1: SQL列名不匹配
**源文件**: `database.py`
**字段**: yfinance返回的Dividends、Stock Splits列
**解决方案**: 过滤到预定义的valid_cols列表

### 问题2: 时区不兼容
**源文件**: `indicators.py` - `align_with_trading_time`方法
**问题**: merge_asof要求相同时区
**解决方案**: 改用reindex + ffill方法

### 问题3: 缺失值导致数据全部丢失 ⚠️ **关键问题**
**源文件**: `main.py` - `build_features`方法
**详细诊断**:

#### 缺失值来源：
1. **VIX数据完全缺失** (100%)
   - `VIX_close`: 2976个缺失值
   - `VIX_return_1d`: 2976个缺失值
   - **原因**: yfinance获取失败

2. **价差统计特征** (30.24%)
   - `spread_skew_20`: 900个缺失值
   - `spread_kurt_20`: 900个缺失值
   - **原因**: 滚动窗口初期数据不足

3. **技术指标** (少量)
   - RSI: 14个缺失值
   - MACD: 1-20个缺失值
   - **原因**: 计算周期需要

4. **目标变量** (5个)
   - `forward_return`: 5个缺失值
   - **原因**: 前瞻5天，尾部缺失

#### 解决方案（已实施）：

**四步清理策略**:
```python
# 步骤1: 前向填充 (ffill)
df = df.ffill()
# 剩余缺失值: 10928 → 7785

# 步骤2: 后向填充 (bfill) 
df = df.bfill()
# 剩余缺失值: 7785 → 5952

# 步骤3: 均值填充
for col in df.columns:
    df[col] = df[col].fillna(df[col].mean())
# 剩余缺失值: 5952 (VIX全空，无法填充)

# 步骤4: 删除完全缺失的列
df = df.dropna(axis=1)
# 删除列: ['VIX_close', 'VIX_return_1d']
```

**最终结果**:
- ✅ **样本保留**: 2976 → 2976 (100%)
- ✅ **特征数**: 127 → 123 (删除2列VIX特征)
- ✅ **无缺失值**: 所有样本完整可用
