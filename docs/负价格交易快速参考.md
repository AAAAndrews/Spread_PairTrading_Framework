## ⚠️ 注意事项

### 1. 价格为零
- 价格恰好为 0 时，无法计算仓位
- 返回 0（避免除零错误）

### 2. 滑点方向
| 价格类型 | 买入 | 卖出 |
|---------|------|------|
| 正价格 | 价格↑ | 价格↓ |
| 负价格 | 价格↓（更负） | 价格↑（更正） |

### 3. 止损计算
- 使用价格绝对值计算百分比
- 确保负价格下也能正确触发

## ✨ 关键改进

| 方法 | 修改前 | 修改后 |
|------|--------|--------|
| `calculate_max_position_size` | `if price <= 0: return 0` | `if abs(price) == 0: return 0` |
| `calculate_slippage` | 不区分正负 | 正负分支处理 |
| `check_stop_loss` | `/entry_price` | `/abs(entry_price)` |
| `update_equity_curve` | `position * price` | `abs(position * price)` |

## 📞 问题排查

### 问题1: 负价格无法开仓
**原因**: 价格检查过于严格  
**解决**: 已修改为仅检查价格是否为0

### 问题2: 负价格止损异常
**原因**: 百分比计算使用负数作为分母  
**解决**: 使用 `abs(entry_price)` 计算

### 问题3: 滑点方向错误
**原因**: 未区分正负价格  
**解决**: 添加正负分支处理
