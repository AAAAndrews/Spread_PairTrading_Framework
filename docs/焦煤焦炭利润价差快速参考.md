# 焦煤焦炭利润价差 - 快速参考卡片

## 🎯 核心公式

```
盘面炼焦利润 = 焦炭价格 - (1.35 × 焦煤价格)
```

**单位**: 元/吨

---

## 📊 快速判断

| 利润值 | 含义 | 预期 |
|--------|------|------|
| > 200 | 💰 高盈利 | 供应增加 |
| 0~200 | ✅ 盈利 | 供应稳定 |
| 0 | ⚖️ 平衡 | 观望 |
| -200~0 | 📉 小亏 | 供应减少 |
| < -200 | ❌ 大亏 | 供应紧缩 |

---

## 🔧 配比系数

| 项目 | 数值 |
|------|------|
| 理论值 | 1.35 |
| 范围 | 1.33 - 1.38 |
| 含义 | 生产1吨焦炭需要的焦煤吨数 |

---

## 💡 计算示例

### 示例1：盈利
```
J (焦炭)  = 2200 元/吨
JM (焦煤) = 1500 元/吨

利润 = 2200 - (1.35 × 1500) = 175 元/吨 ✅
```

### 示例2：亏损
```
J (焦炭)  = 1800 元/吨
JM (焦煤) = 1500 元/吨

利润 = 1800 - (1.35 × 1500) = -225 元/吨 ❌
```

## 📈 交易信号

### 做多价差（买J，卖JM）
- ✅ 利润处于历史低位（< 10分位数）
- ✅ 预期钢厂需求回暖
- ✅ 价差跌破下轨后反弹

### 做空价差（卖J，买JM）
- ✅ 利润处于历史高位（> 90分位数）
- ✅ 预期钢厂需求下降
- ✅ 价差突破上轨后回落

---

## 🔍 关键指标

### 统计指标
- **均值**: 历史平均利润
- **标准差**: 波动程度
- **Z-score**: 当前值偏离均值的倍数
- **分位数**: 在历史数据中的位置

### 技术指标
- **MA20**: 20日移动平均
- **MA60**: 60日移动平均
- **布林带**: 均值 ± 2倍标准差

## ⚡ 快速检查

### Python快速查询
```python
# 当前利润
current_profit = spread_data['COKING_PROFIT']['spread'].iloc[-1]
print(f"当前盘面利润: {current_profit:.2f} 元/吨")

# 历史统计
mean = spread_data['COKING_PROFIT']['spread'].mean()
std = spread_data['COKING_PROFIT']['spread'].std()
print(f"历史均值: {mean:.2f} ± {std:.2f}")

# Z-score
z_score = (current_profit - mean) / std
print(f"Z-score: {z_score:.2f}")

# 分位数
from scipy.stats import percentileofscore
percentile = percentileofscore(
    spread_data['COKING_PROFIT']['spread'], 
    current_profit
)
print(f"分位数: {percentile:.1f}%")
```

## 💡 实战技巧

### 1. 结合基本面
- 焦炭仓单 ↑ → 供应充足 → 利润 ↓
- 焦煤仓单 ↑ → 成本下降 → 利润 ↑
- 港口库存 ↑ → 供应压力 → 利润 ↓

### 2. 关注下游
- 螺纹钢价格 ↑ → 钢厂利润好 → 焦炭需求 ↑ → 利润 ↑
- RB期货走强 → 下游需求旺盛 → 做多价差

### 3. 宏观环境
- PMI > 50 → 制造业扩张 → 钢铁需求 ↑ → 利润 ↑
- 基建投资 ↑ → 钢铁需求 ↑ → 焦炭需求 ↑ → 利润 ↑
