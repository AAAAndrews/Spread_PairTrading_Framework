# 回归任务信号生成功能说明

## 🎯 功能概述

`SignalGenerator` 现在支持**回归任务的阈值逻辑**，可以将连续的回归预测值转换为离散的交易信号（1, 0, -1），支持两种模式：

1. **固定阈值模式**：使用预设的上下阈值
2. **滚动分位数模式**：使用动态计算的分位数作为阈值（推荐）

## 📊 信号生成逻辑

### 分类任务（原有功能）
```
预测类别 + 概率阈值 → 信号
- 预测类别=1 且 概率>threshold → signal=1
- 预测类别=-1 且 概率>threshold → signal=-1
- 其他 → signal=0
```

### 回归任务（新增功能）

#### 模式1：固定阈值
```
预测值 vs 固定阈值 → 信号
- prediction > upper_threshold → signal=1 (做多)
- prediction < lower_threshold → signal=-1 (做空)
- lower_threshold ≤ prediction ≤ upper_threshold → signal=0 (观望)
```

#### 模式2：滚动分位数（推荐）
```
预测值 vs 动态分位数 → 信号
- prediction > rolling_upper_quantile → signal=1
- prediction < rolling_lower_quantile → signal=-1
- 其他 → signal=0
```

**优势**：
- ✅ 自适应市场变化
- ✅ 避免固定阈值失效
- ✅ 自动调整信号频率

## 🔧 参数说明

### 初始化参数

```python
SignalGenerator(
    model,                          # 训练好的MLModel
    threshold=0.6,                  # 分类任务概率阈值
    signal_holding_days=5,          # 信号维持天数
    
    # ✅ 回归任务参数
    regression_upper_threshold=0.05,    # 固定上阈值（5%）
    regression_lower_threshold=-0.05,   # 固定下阈值（-5%）
    use_rolling_quantile=False,         # 是否使用滚动分位数
    rolling_window=60,                  # 滚动窗口大小
    upper_quantile=0.75,                # 上分位数（75%）
    lower_quantile=0.25                 # 下分位数（25%）
)
```

| 参数 | 说明 | 默认值 | 推荐值 |
|-----|------|--------|--------|
| `regression_upper_threshold` | 固定上阈值 | 0.05 | 根据预测目标调整 |
| `regression_lower_threshold` | 固定下阈值 | -0.05 | 负数，对称或非对称 |
| `use_rolling_quantile` | 使用动态分位数 | False | True（推荐） |
| `rolling_window` | 滚动窗口大小 | 60 | 20-120（取决于数据频率） |
| `upper_quantile` | 上分位数 | 0.75 | 0.7-0.85 |
| `lower_quantile` | 下分位数 | 0.25 | 0.15-0.3 |

## 💡 使用示例

### 示例1：固定阈值模式

```python
from src.core.ml_models import MLModel, SignalGenerator
```

## 🎯 参数调优建议

### 滚动窗口大小（rolling_window）

| 数据频率 | 推荐窗口 | 说明 |
|---------|---------|------|
| 日线数据 | 40-80 | 约2-4个月的数据 |
| 周线数据 | 12-26 | 约3-6个月的数据 |
| 月线数据 | 6-12 | 约半年到一年的数据 |

**原则**：
- 窗口太小：阈值过于敏感，信号频繁变化
- 窗口太大：阈值滞后，错过时机

### 分位数选择（upper_quantile, lower_quantile）

| 风格 | 上分位数 | 下分位数 | 信号频率 | 风险 |
|-----|---------|---------|---------|------|
| 保守 | 0.80 | 0.20 | 低（~20%） | 低 |
| 平衡 | 0.75 | 0.25 | 中（~25%） | 中 |
| 激进 | 0.70 | 0.30 | 高（~30%） | 高 |
| 极端 | 0.65 | 0.35 | 很高（~35%） | 很高 |

**原则**：
- 分位数差距大：更保守，只在极端情况开仓
- 分位数差距小：更激进，更频繁交易

### 信号维持天数（signal_holding_days）

根据预测目标调整：
- 预测未来5天收益 → `signal_holding_days=5`
- 预测未来10天收益 → `signal_holding_days=10`
- 预测未来20天收益 → `signal_holding_days=20`

**原则**：信号维持天数应与预测时间窗口一致

## ⚠️ 注意事项

### 1. 预测目标的选择

回归任务的预测目标应该是**有方向性的指标**：
- ✅ 未来收益率：`(price[t+n] - price[t]) / price[t]`
- ✅ 价差变化：`spread[t+n] - spread[t]`
- ✅ 对数收益：`log(price[t+n]) - log(price[t])`
- ❌ 未来价格：不适合直接用于信号生成

### 2. 阈值的合理性

固定阈值应基于**预测值的实际分布**：
```python
# 查看预测值分布
predictions = model.predict(X_test)
print(f"预测值统计:")
print(f"  均值: {predictions.mean():.4f}")
print(f"  标准差: {predictions.std():.4f}")
print(f"  分位数: 25%={np.percentile(predictions, 25):.4f}, "
      f"75%={np.percentile(predictions, 75):.4f}")

# 根据标准差设置阈值
upper_threshold = predictions.std() * 1.0  # 1倍标准差
lower_threshold = -predictions.std() * 1.0
```

### 3. 避免过拟合

- 在验证集上测试不同的分位数配置
- 避免频繁调整参数（参数稳定性很重要）
- 使用walk-forward验证

### 4. 信号强度的使用

`signal_strength` 字段表示信号的强度（0-1），可用于：
- 动态仓位管理：强度越大，仓位越重
- 过滤弱信号：只执行强度>0.5的信号
- 风险管理：强度低时缩小止损范围

## 📚 对比：固定阈值 vs 滚动分位数

| 特性 | 固定阈值 | 滚动分位数 |
|-----|---------|-----------|
| **适应性** | ❌ 静态 | ✅ 动态适应 |
| **参数调优** | 简单 | 需要调优窗口和分位数 |
| **市场变化** | ❌ 可能失效 | ✅ 自动调整 |
| **信号稳定性** | ✅ 稳定 | ⚠️ 可能变化 |
| **计算成本** | ✅ 低 | ⚠️ 中等 |
| **推荐场景** | 稳定市场 | 动态市场（推荐） |

## 🎓 最佳实践

1. **优先使用滚动分位数**：除非有充分理由使用固定阈值
2. **窗口大小 = 2-4个月**：对于日线数据
3. **分位数 [0.25, 0.75]**：作为起点，根据回测调整
4. **信号维持 = 预测窗口**：保持一致性
5. **监控阈值变化**：确保不会过于频繁变动
6. **结合风险管理**：使用止损和仓位管理
