# 螺纹钢(RB)下游行业指标说明

## 📋 概述

螺纹钢期货(RB)已作为**下游行业需求指标**整合到焦炭焦煤价差交易策略中。

### 为什么添加螺纹钢？

**供应链关系**：
```
焦煤 → 焦炭 → 螺纹钢（钢铁产品）
原料    中间产品   最终产品
```

- **焦煤**：炼焦的原材料
- **焦炭**：焦煤炼制而成，是炼钢的主要燃料
- **螺纹钢**：使用焦炭冶炼的钢铁产品

**逻辑**：
- 螺纹钢需求增加 → 钢厂增产 → 焦炭需求上升 → 焦煤需求上升
- 螺纹钢价格是下游需求的直接反映
- RB价格波动可预测焦炭焦煤的需求变化

## 🔧 实现细节

### 1. 数据获取

**位置**：步骤1.2 - 获取螺纹钢数据

```python
# 从akshare获取螺纹钢主力连续合约(RB0)
rb_raw = ak.futures_zh_daily_sina(symbol="RB0")
rb_df = rb_raw.copy()
rb_df.index = pd.to_datetime(rb_df['date'])
rb_df.index = rb_df.index.tz_localize('UTC')

# 存入数据库
for idx, row in rb_df.iterrows():
    db.insert_price_data(
        symbol='RB',
        date=idx.strftime('%Y-%m-%d'),
        data={
            'open': float(row['open']),
            'high': float(row['high']),
            'low': float(row['low']),
            'close': float(row['close']),
            'volume': float(row['volume']) if pd.notna(row['volume']) else None
        },
        data_type='downstream'  # 标记为下游数据
    )
```

### 2. 数据提取

**位置**：步骤1.2 - 从数据库提取螺纹钢数据

```python
# 从数据库提取
rb_df = db.get_price_data('RB', start_date=START_DATE)

# 存储在macro_data字典中（作为宏观/下游指标）
macro_data['RB'] = rb_df

# 计算与焦炭、焦煤的相关性
if 'JM' in price_data:
    jm_close = price_data['JM']['close']
    common_dates = rb_close.index.intersection(jm_close.index)
    corr_jm = rb_close.loc[common_dates].corr(jm_close.loc[common_dates])
    print(f"螺纹钢 vs 焦煤: {corr_jm:.4f}")
```

### 3. 特征工程

**位置**：步骤3.5 - 创建宏观特征

螺纹钢被纳入宏观特征循环：

```python
# 在特征工程中，RB与VIX、DXY一起处理
for symbol in ['VIX', 'DXY', 'RB']:  # 👈 RB已添加
    df = db.get_price_data(symbol)
    if not df.empty and 'close' in df.columns:
        # 创建RB_close和RB_return_1d特征
        macro_df = df[['close']].copy()
        macro_df[f'{symbol}_return_1d'] = macro_df['close'].pct_change()
        
        # 使用merge_asof进行时间对齐
        temp_macro = pd.merge_asof(
            temp_macro.sort_values('date'),
            macro_df[['date', f'{symbol}_close', f'{symbol}_return_1d']].sort_values('date'),
            on='date',
            direction='backward'
        )
```

**生成的特征**：
- `RB_close`：螺纹钢收盘价
- `RB_return_1d`：螺纹钢日收益率

## 🔍 相关性分析

### 理论预期

**正相关关系**：
- 螺纹钢价格上涨 → 钢厂利润改善 → 增加产量
- 增加产量 → 焦炭需求增加 → 焦炭价格上涨
- 焦炭价格上涨 → 焦煤需求增加 → 焦煤价格上涨

### 实际验证

代码会自动计算相关性：
```python
螺纹钢 vs 焦煤: 0.8234  # 示例值
螺纹钢 vs 焦炭: 0.8456  # 示例值
```

**解读**：
- 相关性 > 0.7：强正相关，符合预期
- 相关性 0.3-0.7：中等相关
- 相关性 < 0.3：弱相关或不相关

## 📈 在策略中的作用

### 1. 需求预测

- **RB价格上涨** → 下游需求旺盛
  - 可能导致焦炭焦煤价差扩大（焦炭涨幅更大）
  - 交易信号：做多焦炭，做空焦煤

- **RB价格下跌** → 下游需求疲软
  - 可能导致焦炭焦煤价差收窄
  - 交易信号：做空焦炭，做多焦煤

### 2. 特征重要性

在模型训练后，可以查看RB特征的重要性：
```python
# 特征重要性排名
RB_close:        0.082  (排名第5)
RB_return_1d:    0.045  (排名第12)
```

高重要性 → RB对价差预测有显著贡献

### 3. 时间对齐

使用 `merge_asof` 确保：
- RB数据与焦炭焦煤数据正确对齐
- 向后填充缺失日期（使用最近的历史数据）
- 避免未来信息泄露

## 🛠️ 常见问题

### Q1: 为什么RB存储在macro_data而不是price_data？

**A**: 虽然RB也是期货价格，但它的作用是作为**宏观需求指标**，类似于VIX（波动率指标）和DXY（美元指数）的作用，因此归类为macro_data更合适。

### Q2: RB数据从哪个日期开始？

**A**: 从START_DATE（通常是"2000-01-01"）开始，但实际数据取决于akshare的历史数据可用性。螺纹钢期货(RB)在中国大约2009年上市。

### Q3: 如果RB数据缺失怎么办？

**A**: 
```python
# merge_asof使用direction='backward'
# 会自动向后填充最近的历史数据
# 如果完全没有RB数据，该特征列会是NaN
# 在dropna()时会被移除相应的行
```

### Q4: 如何查看RB特征是否生效？

**A**:
```python
# 在特征工程后运行：
print(macro_features.columns)
# 应该包含：['VIX_close', 'VIX_return_1d', 'DXY_close', 'DXY_return_1d', 
#           'RB_close', 'RB_return_1d']

# 查看RB特征重要性：
print(model.feature_importance)
# 找到包含'RB'的特征
```

### Q5: RB数据是否需要单位转换？

**A**: **不需要**。RB价格已经是人民币/吨，不需要像裂解价差那样进行单位转换（加仑→桶）。
