## 💡 在价差套利中的应用

### 1. 作为基本面因子
```python
# 获取库存数据
crude_stock = fetcher.fetch_eia_data('PET.WCRSTUS1.W')
gasoline_stock = fetcher.fetch_eia_data('PET.WGTSTUS1.W')

# 计算库存Z分数
crude_zscore = (crude_stock - crude_stock.rolling(52).mean()) / crude_stock.rolling(52).std()

# 作为特征添加到模型
features['crude_stock_zscore'] = crude_zscore
```

### 2. 信号验证
- 库存高 + 价差收窄 → 增强做空信号
- 库存低 + 价差扩大 → 增强做多信号

### 3. 风险管理
- 库存异常波动 → 降低仓位
- 库存趋势与价差背离 → 谨慎交易

## 🔧 技术实现细节

### API请求流程
```
1. 构造URL: https://api.eia.gov/v2/seriesid/{series_id}
2. 添加参数: api_key
3. 发送GET请求
4. 解析JSON响应
5. 转换为pandas DataFrame
6. 处理日期和时区
7. 返回标准化数据
```

- ✅ 网络错误捕获
