# 期货杠杆交易回测功能说明

## 🎯 功能概述

回测引擎 `BacktestEngine` 现已支持**期货杠杆交易**，模拟真实的期货保证金制度，让回测更贴近实际交易。

## 📊 杠杆原理

### 传统股票交易（无杠杆）
```
资金: 100万
买入: 需要支付 100万 现金
持仓价值: 100万
```

### 期货杠杆交易（10倍杠杆）
```
资金: 100万
保证金比例: 10%
杠杆: 10倍

可控制价值 = 100万 × 10 = 1000万
所需保证金 = 1000万 × 10% = 100万
剩余可用资金 = 100万 - 100万 = 0

如果价格涨10%:
  盈利 = 1000万 × 10% = 100万 (收益率100%)
  
如果价格跌10%:
  亏损 = 1000万 × 10% = 100万 (爆仓风险！)
```

## 🔧 参数说明

### `BacktestEngine` 初始化参数

```python
BacktestEngine(
    initial_capital=1000000,      # 初始资金
    commission_rate=0.0005,       # 手续费率
    slippage_rate=0.0001,         # 滑点率
    max_position=100,             # 最大持仓数量
    
    # ✅ 杠杆相关参数
    leverage=10.0,                # 杠杆倍数
    margin_ratio=0.1,             # 保证金比例 (10%)
    max_capital_usage=0.8         # 最大资金使用率 (80%)
)
```

| 参数 | 说明 | 典型值 | 影响 |
|-----|------|--------|------|
| `leverage` | 杠杆倍数 | 5-15 | 越高风险越大，潜在收益也越大 |
| `margin_ratio` | 保证金比例 | 0.08-0.15 | 交易所规定，不同品种不同 |
| `max_capital_usage` | 最大资金使用率 | 0.5-0.9 | 控制总体风险敞口 |

### 不同杠杆水平对比

| 杠杆 | 保证金 | 风险等级 | 适用场景 |
|-----|--------|---------|---------|
| 1x | 100% | ⭐ 低 | 保守型，相当于股票 |
| 5x | 20% | ⭐⭐ 中低 | 稳健型，推荐新手 |
| 10x | 10% | ⭐⭐⭐ 中 | 平衡型，常用配置 |
| 15x | 6.7% | ⭐⭐⭐⭐ 高 | 激进型，需经验 |
| 20x | 5% | ⭐⭐⭐⭐⭐ 极高 | 高频交易，不推荐 |

```python
import pandas as pd
```

## 📊 杠杆效果对比

### 场景：原油价格70美元/桶，资金100万

#### 无杠杆（leverage=1）
```
可开仓位 = 100万 / 70 = 14,285手
实际开仓 = 100手（受max_position限制）
占用资金 = 100 × 70 = 7,000美元
资金占用率 = 0.7%

价格涨到77美元（+10%）:
  盈利 = 100 × (77-70) = 700美元
  收益率 = 700 / 100万 = 0.07%  ❌ 太低
```

#### 10倍杠杆（leverage=10）
```
可用于交易 = 100万 × 80% = 80万
杠杆放大 = 80万 × 10 = 800万
可开仓位 = 800万 / 70 = 114,285手
实际开仓 = 100手（受max_position限制）
所需保证金 = 100 × 70 × 10% = 700美元
保证金占用率 = 0.07%

价格涨到77美元（+10%）:
  盈利 = 100 × (77-70) = 700美元
  收益率 = 700 / 100万 = 0.07%  ✅ 相同
  
但是：
  杠杆后实际可开 = 1,000手（如果放宽max_position）
  盈利 = 1,000 × 7 = 7,000美元
  收益率 = 7,000 / 100万 = 0.7%  ✅ 10倍收益！
```

```python
# 根据市场波动率调整杠杆
def adjust_leverage_by_volatility(base_leverage, volatility):
    """波动率越高，杠杆越低"""
    if volatility > 0.03:  # 高波动
        return base_leverage * 0.5
    elif volatility > 0.02:  # 中波动
        return base_leverage * 0.75
    else:  # 低波动
        return base_leverage
```

## 🧪 对比测试

### 运行多个杠杆水平对比

```python
leverages = [1, 5, 10, 15]
results = {}

for lev in leverages:
    engine = BacktestEngine(
        initial_capital=1000000,
        leverage=lev,
        margin_ratio=1.0/lev,  # 保持一致
        max_capital_usage=0.8
    )
    
    equity_curve = engine.run_backtest(price_data, signals)
    analyzer = PerformanceAnalyzer(equity_curve)
    
    results[f'{lev}x杠杆'] = {
        '总收益率': analyzer.calculate_total_return(),
        '夏普比率': analyzer.calculate_sharpe_ratio(),
        '最大回撤': analyzer.calculate_max_drawdown()['max_drawdown'],
        '波动率': analyzer.calculate_volatility()
    }

# 对比结果
comparison_df = pd.DataFrame(results).T
print(comparison_df)
```

### 预期结果

```
           总收益率    夏普比率    最大回撤      波动率
1x杠杆      0.15      1.2      -0.08      0.12
5x杠杆      0.75      1.5      -0.25      0.35
10x杠杆     1.50      1.3      -0.45      0.70
15x杠杆     2.25      0.9      -0.70      1.20
```

**观察**：
- 杠杆越高，收益越高，但夏普比率下降
- 回撤和波动率成倍增加
- 需要在收益和风险之间平衡
