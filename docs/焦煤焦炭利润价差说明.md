# 焦煤焦炭利润价差说明

## 📋 概述

**焦煤焦炭利润价差**是基于"虚拟焦化厂"模型计算的盘面炼焦利润，反映了焦化行业的理论盈利水平。

---

## 🔬 计算方法

### 公式

```
盘面炼焦利润 = (1 × 焦炭期货价格) - (K × 焦煤期货价格)
```

其中：
- **焦炭价格 (J)**：焦炭期货收盘价（元/吨）
- **焦煤价格 (JM)**：焦煤期货收盘价（元/吨）
- **配比系数 (K)**：生产1吨焦炭所需的焦煤吨数

### 配比系数 K

| 类型 | 数值 | 说明 |
|------|------|------|
| **理论值** | 1.35 | 行业标准配比 |
| **实际范围** | 1.33 - 1.38 | 根据原料品质和工艺微调 |
| **本策略使用** | 1.35 | 取理论中值 |

**影响因素**：
- 焦煤的挥发分
- 焦煤的硫分
- 焦煤的粘结指数
- 焦化厂的工艺水平

---

## 💡 计算示例

### 示例1：盈利情况

```
焦炭价格 (J)  = 2200 元/吨
焦煤价格 (JM) = 1500 元/吨
配比系数 (K)  = 1.35

盘面利润 = 2200 - (1.35 × 1500)
         = 2200 - 2025
         = 175 元/吨 ✅ 盈利
```

**解读**：焦化厂每生产1吨焦炭，理论盈利175元。

### 示例2：亏损情况

```
焦炭价格 (J)  = 1800 元/吨
焦煤价格 (JM) = 1500 元/吨
配比系数 (K)  = 1.35

盘面利润 = 1800 - (1.35 × 1500)
         = 1800 - 2025
         = -225 元/吨 ❌ 亏损
```

**解读**：焦化厂每生产1吨焦炭，理论亏损225元。

## 📊 价差意义

### 1. 行业盈利指标

| 盘面利润 | 状态 | 焦化厂反应 | 供应预期 |
|---------|------|-----------|---------|
| > 200元/吨 | 💰 高盈利 | 积极生产，增产 | 供应增加 |
| 0 ~ 200元/吨 | ✅ 盈利 | 正常生产 | 供应稳定 |
| 0元/吨 | ⚖️ 盈亏平衡 | 维持生产 | 供应观望 |
| -200 ~ 0元/吨 | 📉 小亏 | 减产或停产 | 供应减少 |
| < -200元/吨 | ❌ 大亏 | 大规模停产 | 供应紧缩 |

### 2. 供需关系预测

**利润扩大（价差上升）**：
- 焦炭价格上涨 > 焦煤价格上涨
- 可能原因：钢厂需求旺盛，焦炭供应紧张
- 预期：焦化厂增产，焦煤需求增加

**利润收窄（价差下降）**：
- 焦炭价格下跌 > 焦煤价格下跌
- 可能原因：钢厂需求疲软，焦炭供应过剩
- 预期：焦化厂减产，焦煤需求减少

### 3. 交易信号

**做多价差（买焦炭，卖焦煤）**：
- 当前利润处于历史低位
- 预期钢厂需求回暖
- 技术指标显示价差触底

**做空价差（卖焦炭，买焦煤）**：
- 当前利润处于历史高位
- 预期钢厂需求下降
- 技术指标显示价差见顶

**单元格**：步骤2.1 - 计算焦煤焦炭利润价差

### 核心代码

```python
# 配比系数
COKING_RATIO = 1.35

# 注册价差配置
spread_calc.register_spread(
    name='COKING_PROFIT',
    components={
        'J': 1.0,              # 焦炭价格系数
        'JM': -COKING_RATIO    # 焦煤价格系数（负数表示成本）
    },
    description=f'焦化厂盘面利润 = 1×焦炭价格 - {COKING_RATIO}×焦煤价格'
)

# 计算价差
coking_spread_df = spread_calc.calculate_spread(
    'COKING_PROFIT',
    price_data,
    price_column='close'
)

# 添加统计特征
coking_spread_df = spread_calc.get_spread_statistics(coking_spread_df, window=20)
spread_data['COKING_PROFIT'] = coking_spread_df
```

## 🎯 交易策略应用

### 1. 均值回归策略

**逻辑**：利润偏离历史均值时，倾向回归

```python
# 计算Z-score
z_score = (current_profit - mean_profit) / std_profit

if z_score < -2:
    signal = 1  # 做多价差（买焦炭，卖焦煤）
elif z_score > 2:
    signal = -1  # 做空价差（卖焦炭，买焦煤）
else:
    signal = 0  # 观望
```

### 2. 趋势跟踪策略

**逻辑**：价差突破移动平均线

```python
if profit > ma20 and profit > ma60:
    signal = 1  # 上升趋势，做多价差
elif profit < ma20 and profit < ma60:
    signal = -1  # 下降趋势，做空价差
```

### 3. 极值策略

**逻辑**：基于历史分位数

```python
percentile = calculate_percentile(current_profit)

if percentile < 10:
    signal = 1  # 历史低位，做多价差
elif percentile > 90:
    signal = -1  # 历史高位，做空价差
```

## 🔍 与其他指标的关系

### 1. 基本面数据

| 指标 | 关系 | 说明 |
|------|------|------|
| 焦炭仓单 | 负相关 | 仓单增加→供应充足→利润下降 |
| 焦煤仓单 | 正相关 | 仓单增加→成本下降→利润上升 |
| 港口库存 | 负相关 | 库存高→供应压力→利润下降 |

### 2. 下游需求

| 指标 | 关系 | 说明 |
|------|------|------|
| 螺纹钢价格 (RB) | 正相关 | 钢价高→焦炭需求强→利润上升 |
| RB-J价差 | 同向 | 钢厂利润好→焦化利润也好 |

### 3. 宏观指标

| 指标 | 关系 | 说明 |
|------|------|------|
| PMI | 正相关 | 制造业景气→钢铁需求→利润上升 |
| 固定资产投资 | 正相关 | 基建投资→钢铁需求→利润上升 |

## ⚠️ 注意事项

### 1. 配比系数选择

- **默认1.35**：适用于大多数情况
- **调整建议**：如果有焦化厂实际配煤比数据，可以根据实际情况调整
- **区间**：建议在1.33-1.38之间

### 2. 成本考虑

公式计算的是**盘面理论利润**，实际利润还需考虑：
- 加工费用（人工、设备、能源）
- 环保成本
- 运输费用
- 其他生产成本

通常实际盈亏平衡点不是0，而是正值（如50-100元/吨）。

### 3. 市场因素

价差变化受多种因素影响：
- 供需关系（最主要）
- 环保限产政策
- 进口煤政策
- 季节性因素
- 突发事件

### 4. 数据质量

- 使用主力连续合约数据
- 确保数据时间对齐
- 检查异常值
- 考虑合约换月影响

## 📞 技术支持

### 常见问题

**Q1: 为什么我的价差一直是负值？**

A: 可能原因：
1. 焦煤价格相对焦炭过高
2. 行业处于亏损周期
3. 配比系数K值需要调整

**Q2: 价差的标准差很大，如何处理？**

A: 价差波动大是正常的，可以：
1. 使用Z-score标准化
2. 计算滚动标准差
3. 使用百分位数而非绝对值

**Q3: 如何将价差用于实际交易？**

A: 建议：
1. 结合基本面数据
2. 参考技术指标
3. 设置止损止盈
4. 考虑资金管理
