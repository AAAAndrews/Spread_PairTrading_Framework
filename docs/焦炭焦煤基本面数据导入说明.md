## 🔍 时区处理

**重要**: 所有日期时间均使用东八区时区 (Asia/Shanghai)

```python
# 导入时添加时区
df['date'] = df['date'].dt.tz_localize('Asia/Shanghai')

# 提取时也保持时区
inventory_df['report_date'] = inventory_df['report_date'].dt.tz_localize('Asia/Shanghai')
```

## 💾 数据库存储

数据存储在 `fundamental_data` 表中：

```sql
SELECT * FROM fundamental_data 
WHERE data_source = 'COAL_INVENTORY'
ORDER BY report_date DESC
LIMIT 10;
```

## 🎯 使用建议

1. **数据更新**: 定期运行导入脚本更新数据
2. **缺失值处理**: 基本面数据可能存在缺失，已使用前向填充处理
3. **时间对齐**: 使用 `merge_asof` 确保与价格数据正确对齐
4. **特征选择**: 在模型训练时可以查看特征重要性，筛选有效的基本面指标

## 🐛 常见问题

**Q1: 导入时出现编码错误？**
A: CSV文件默认使用UTF-8编码，如果出错请检查文件编码

**Q2: 数据提取为空？**
A: 确保先运行了导入单元格，并检查数据库路径是否正确

**Q3: 时区不一致？**
A: 所有基本面数据统一使用东八区，与价格数据的UTC时区在合并时会自动处理

**Q4: 特征没有被使用？**
A: 检查是否在原特征工程单元格的 `all_features_list` 中添加了 `fundamental_features`
