# 止损功能使用说明

## 📋 概述

回测引擎现已支持**单笔交易硬止损**功能，可以在持仓亏损达到设定阈值时自动平仓，有效控制风险。

---

## 🔧 止损参数

### 1. 百分比止损 (`stop_loss_pct`)

基于开仓价格的跌幅百分比触发止损。

```python
stop_loss_pct = 0.05  # 5%止损
```

**触发条件**：
- **多头**：当前价格 < 开仓价格 × (1 - 5%) 时触发
- **空头**：当前价格 > 开仓价格 × (1 + 5%) 时触发

**示例**：
```
开仓价格: $100
止损线: $95 (下跌5%)
当价格跌至$95时，自动平仓
```

### 2. 金额止损 (`stop_loss_amount`)

基于绝对金额的亏损触发止损。

```python
stop_loss_amount = 5000  # 亏损$5000止损
```

**触发条件**：
- 浮动亏损 ≥ $5000 时触发

**示例**：
```
持仓: 100手
开仓价格: $100
当前价格: $50
浮动亏损: (100 - 50) × 100 = $5000
触发止损，自动平仓
```

### 3. 同时设置

可以同时设置两种止损，**先触发哪个就执行哪个**。

```python
stop_loss_pct = 0.05      # 5%止损
stop_loss_amount = 5000   # $5000止损
# 任一条件达到即触发
```

## 💻 使用方法

### 基本用法

```python
from src.core.backtest import BacktestEngine

# 创建回测引擎（带止损）
backtest_engine = BacktestEngine(
    initial_capital=1000000,
    commission_rate=0.0005,
    slippage_rate=0.0001,
    max_position=100,
    leverage=10.0,

# 运行回测

    spread_prices,
    signals,
    price_col='close',
    volatility_col='volatility'
)
```

```python
)
```

## 🔍 止损逻辑说明

### 检查时机

止损检查发生在**每个时间步更新权益之前**：

```python
# 回测循环
for timestamp, row in data.iterrows():
    price = row['close']
    signal = row['signal']
    
    # 1. 先检查止损
    if check_stop_loss(price):
        execute_trade(timestamp, 0, price)  # 强制平仓
        continue  # 跳过本次信号
    
    # 2. 执行正常交易信号
    execute_trade(timestamp, signal, price)
```

### 浮动盈亏计算

**多头仓位**：
```python
unrealized_pnl = (current_price - entry_price) × position
price_change_pct = (current_price - entry_price) / entry_price
```

**空头仓位**：
```python
unrealized_pnl = (entry_price - current_price) × |position|
price_change_pct = (entry_price - current_price) / entry_price
```

### 止损判断

```python
# 百分比止损
if price_change_pct <= -stop_loss_pct:
    trigger_stop_loss()

# 金额止损
if unrealized_pnl <= -stop_loss_amount:
    trigger_stop_loss()
```

## 📈 止损参数选择建议

### 1. 根据波动率设置

| 资产波动率 | 建议止损 | 说明 |
|-----------|---------|------|
| 低波动 (< 1%) | 2-3% | 债券、外汇 |
| 中波动 (1-3%) | 3-5% | 股指、贵金属 |
| 高波动 (> 3%) | 5-10% | 商品期货、加密货币 |

### 2. 根据资金管理

```python
# 单笔风险不超过总资金的2%
initial_capital = 1000000
risk_per_trade = 0.02  # 2%
stop_loss_amount = initial_capital * risk_per_trade  # $20,000
```

### 3. 根据策略特点

| 策略类型 | 建议止损 |
|---------|---------|
| 高频交易 | 1-2% |
| 日内交易 | 2-5% |
| 波段交易 | 5-10% |
| 长期持有 | 10-20% |

## ⚠️ 注意事项

### 1. 止损与滑点

止损执行时会考虑滑点：
```python
# 卖出时的实际成交价
actual_price = stop_loss_price × (1 - slippage_rate)
```

### 2. 止损与手续费

止损平仓会产生手续费，影响最终盈亏：
```python
final_pnl = unrealized_pnl - commission
```

### 3. 频繁止损

如果止损触发过于频繁，可能需要：
- 放宽止损线
- 优化交易策略
- 减少持仓规模

### 4. 止损重置

每次新开仓时，止损计数会重置：
```python
# 第一次开仓
entry_price = 100  # 止损线: 95

# 平仓后再开仓
entry_price = 110  # 止损线重新计算: 104.5
```

### 示例2：对比不同止损参数

```python
import pandas as pd
import matplotlib.pyplot as plt

# 测试不同止损参数
stop_loss_configs = [
    {'pct': 0, 'amount': 0, 'label': '无止损'},
    {'pct': 0.03, 'amount': 0, 'label': '3%止损'},
    {'pct': 0.05, 'amount': 0, 'label': '5%止损'},
    {'pct': 0.10, 'amount': 0, 'label': '10%止损'},
]

results = []

for config in stop_loss_configs:
    engine = BacktestEngine(
        initial_capital=1000000,
        stop_loss_pct=config['pct'],
        stop_loss_amount=config['amount']
    )
    
    equity_curve = engine.run_backtest(spread_prices, signals)
    
    results.append({
        'label': config['label'],
        'equity_curve': equity_curve,
        'final_equity': equity_curve['equity'].iloc[-1],
        'stop_loss_count': engine.stop_loss_triggered_count
    })

# 绘制对比图
fig, axes = plt.subplots(2, 1, figsize=(15, 10))

# 权益曲线
ax1 = axes[0]
for result in results:
    ax1.plot(result['equity_curve'].index, 
             result['equity_curve']['equity'],
             label=result['label'])
ax1.set_title('不同止损参数的权益曲线对比')
ax1.set_ylabel('权益 ($)')
ax1.legend()
ax1.grid(True)

# 最终权益对比
ax2 = axes[1]
labels = [r['label'] for r in results]
final_equities = [r['final_equity'] for r in results]
stop_loss_counts = [r['stop_loss_count'] for r in results]

x = range(len(labels))
ax2.bar(x, final_equities, alpha=0.7, label='最终权益')
ax2.set_xticks(x)
ax2.set_xticklabels(labels)
ax2.set_ylabel('最终权益 ($)')
ax2.set_title('最终权益对比')

# 添加止损次数标注
for i, (equity, count) in enumerate(zip(final_equities, stop_loss_counts)):
    ax2.text(i, equity, f'{count}次止损', 
             ha='center', va='bottom')

plt.tight_layout()
plt.savefig('outputs/stop_loss_comparison.png', dpi=300)
plt.show()

# 打印统计
print("\n止损参数对比:")
print("-" * 60)
for result in results:
    print(f"{result['label']:12} | "
          f"最终权益: ${result['final_equity']:>12,.2f} | "
          f"止损次数: {result['stop_loss_count']:>3}")
```

## 💡 最佳实践

### 1. 初始测试

先用较宽的止损（如10%）测试策略基本表现，再逐步收紧。

### 2. 避免过度止损

止损太紧会导致频繁止损，增加交易成本，降低盈利机会。

### 3. 结合仓位管理

```python
# 高风险策略 → 低仓位 + 紧止损
backtest_engine = BacktestEngine(
    max_capital_usage=0.5,   # 50%资金使用率
    stop_loss_pct=0.03       # 3%止损
)

# 低风险策略 → 高仓位 + 宽止损
backtest_engine = BacktestEngine(
    max_capital_usage=0.8,   # 80%资金使用率
    stop_loss_pct=0.10       # 10%止损
)
```

### 4. 监控止损效果

定期检查止损触发情况：
- 触发过多 → 止损太紧或策略有问题
- 从不触发 → 止损可能过宽
- 适度触发 → 止损设置合理
