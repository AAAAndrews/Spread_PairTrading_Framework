## 🔍 数据流程

```
1. 获取数据
   akshare (RB0) → UTC时区 → database (type='downstream')

2. 提取数据
   database → macro_data['RB'] → 相关性分析

3. 特征工程
   macro_data['RB'] → merge_asof对齐 → macro_features
   生成特征：RB_close, RB_return_1d

4. 模型训练
   macro_features → 特征选择 → 模型输入
```

## 🔗 供应链关系

```
焦煤 (JM) → 焦炭 (J) → 螺纹钢 (RB)
原料      中间产品    最终产品
```

- RB价格上涨 → 钢厂增产 → 焦炭需求↑ → 焦煤需求↑
- RB价格下跌 → 钢厂减产 → 焦炭需求↓ → 焦煤需求↓

**预期相关性**：RB与JM、J呈正相关（通常>0.7）

---

## ⚠️ 注意事项

1. **数据源**：使用akshare的RB0（螺纹钢主力连续合约）
2. **数据类型**：标记为`downstream`（下游数据）
3. **存储位置**：`macro_data['RB']`（作为宏观指标）
4. **时间对齐**：使用`merge_asof`向后填充缺失日期
5. **单位**：人民币/吨（无需单位转换）
