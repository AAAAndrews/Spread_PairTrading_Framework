## 概述

本次修改使回测系统支持负价格交易，这对于某些价差策略（如价差可能为负）或特殊市场情况（如负油价）非常重要。

## 详细修改内容

### 1. `calculate_max_position_size` 方法

**修改前问题：**
- 使用 `if price <= 0: return 0` 直接拒绝负价格
- 无法计算负价格下的最大仓位

**修改后：**
```python
# 对于负价格，使用绝对值计算合约数量
abs_price = abs(price)

if abs_price == 0:
    return 0

# ... 后续计算使用 abs_price
max_contracts = int(max_contract_value / abs_price)
```

**效果：**
- ✅ 支持负价格计算最大仓位
- ✅ 仅在价格为0时返回0（避免除零错误）
- ✅ 使用价格绝对值进行合约数量计算

---

### 2. `calculate_slippage` 方法

**修改前问题：**
- 对正负价格使用相同的滑点计算逻辑
- 负价格下滑点方向可能不符合预期

**修改后：**
```python
if price >= 0:
    # 正价格的标准处理
    if action == 'buy':
        return price * (1 + self.slippage_rate)
    else:  # sell
        return price * (1 - self.slippage_rate)
else:
    # 负价格的特殊处理：滑点方向相反
    if action == 'buy':
        # 买入负价格资产，价格变得更负（对买方不利）
        return price * (1 + self.slippage_rate)
    else:  # sell
        # 卖出负价格资产，价格变得更正（对卖方不利）
        return price * (1 - self.slippage_rate)
```

**效果：**
- ✅ 正价格：买入时价格增加，卖出时价格减少
- ✅ 负价格：买入时价格更负，卖出时价格更正
- ✅ 确保滑点始终对交易者不利

---

**效果：**

- ✅ 提高代码可读性

### 4. `calculate_margin_required` 方法

**修改前状态：**

**修改：**

- 强调保证金基于价格绝对值计算

**效果：**
- ✅ 保持原有正确逻辑

### 5. `check_stop_loss` 方法

**修改前问题：**
- 价格变化百分比计算：`(current_price - entry_price) / entry_price`
- 当 `entry_price` 为负时，除法可能产生错误的结果
- 例如：从-10涨到-5，计算为(-5 - (-10)) / -10 = -0.5（-50%），但实际是好转

**修改后：**
```python
# 多头
if self.entry_price != 0:
    price_change_pct = (current_price - self.entry_price) / abs(self.entry_price)
else:
    price_change_pct = 0

# 空头
if self.entry_price != 0:
    price_change_pct = (self.entry_price - current_price) / abs(self.entry_price)
else:
    price_change_pct = 0
```

**效果：**
- ✅ 使用 `abs(self.entry_price)` 作为分母
- ✅ 避免负价格导致的符号混淆
- ✅ 正确计算价格变化百分比用于止损判断
- ✅ 添加除零保护

---

### 6. `update_equity_curve` 方法

**修改前问题：**
- 杠杆率计算直接使用 `self.position * current_price`
- 负价格时可能产生负的持仓价值

**修改后：**
```python
# 杠杆率计算（使用价格绝对值）
position_value = abs(self.position * current_price)
leverage_ratio = position_value / total_equity if total_equity > 0 else 0.0
```

**效果：**
- ✅ 持仓价值始终为正
- ✅ 杠杆率计算更准确
- ✅ 代码更清晰易读

## 应用场景

### 1. 价差交易策略
当交易价差时，价差值可能为负：
```python
# 例如：豆油 - 棕榈油价差
spread = soybean_oil_price - palm_oil_price  # 可能为负
```

### 2. 特殊市场情况
某些市场条件下价格可能为负：
- 2020年4月原油期货负价格事件
- 某些金融衍生品的理论价格

### 3. 合成资产
通过多空组合构建的合成资产价格可能为负：
```python
# 例如：裂解价差
crack_spread = gasoline_price + diesel_price - 2 * crude_oil_price
```

## 注意事项

### 1. 价格为零的情况
- 价格恰好为0时，无法计算仓位（返回0）
- 这是正确的行为，避免除零错误

### 2. 止损逻辑
- 使用价格绝对值计算百分比变化
- 确保止损在负价格下也能正确触发

### 3. 滑点方向
- 负价格时滑点方向已自动处理
- 买入时价格变得更负，卖出时价格变得更正
- 始终对交易者不利（符合实际市场情况）

### 4. 盈亏计算
- 盈亏计算逻辑保持不变
- 多头：`(current_price - entry_price) * position`
- 空头：`(entry_price - current_price) * abs(position)`
- 无论价格正负，公式都正确工作
