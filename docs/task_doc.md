# 任务1：构建一个价差套利辅助框架

## 1. 数据模块

### 1.1 数据抓取和存储

- 利用akshare、yfinance、full_fred等Python库，以及其他公开数据源URL进行数据抓取，同时支持导入CSV文件对数据库进行覆写或更新
- 配比组件：对不同品种的行情数据按照指定比例构造出套利价差，如1:1、3:2:1（裂解价差多头3，空头2+1）
- 对不同API数据源进行统一封装，确保不同品种量价数据格式一致（至少包含开高收低成交量）。基本面数据或预测自变量数据不做强制格式一致，但需保留日期时间戳和写入时间等关键字段，时间戳必须带有时区信息
- 对于不存在的数据表直接覆盖完成首次写入；已存在的数据表进行更新写入：检查完全一致的数据记录并跳过，仅插入新数据
- 自行设计数据库结构，使用SQLite3完成本地数据库部署
- 支持通过装饰器对自定义爬虫函数结果进行重构，保证存储数据符合规范

### 1.2 数据基本要求

- 包含指定中国和美国期货品种和股票/商品ETF行情数据的抓取（确保期货主力合约数据及价格指数数据成功提取）
- 行情数据：每个品种至少包含开高收低成交量，字段名称大小写必须一致
- 基本面数据：如EIA报告数据、COT报告数据等，要求含有日期时间戳、数据内容和发布时间戳
- 设计合理机制解决主力合约因移仓换月发生的价格跳变问题，完成期货品种数据的“复权”操作

### 1.3 提取功能

- 支持在Python API中进行数据提取，包含日期/发布日期筛选参数、字段内容参数

## 2. 指标/特征构建模块

### 2.1 处理函数

- 对数据模块中的数据进行按可复用的自定义规则（如减去滚动均值、n步差分）处理，输出样式一致、带有能与指定价差标的交易时间对齐的时间戳的数据
- 支持自定义命名指标并存储数据，数据存储规则参照数据模块要求

### 2.2 对齐模块

- 通过选取数据库中已存在的指标数据，按照特定价差数据的交易时间，进行merge_asof（backward）时间戳对齐，生成多指标数据集并避免未来数据泄露

### 2.3 检验函数

- 引入adfuller单位根检验，检验指标或指定序列的平稳性，报告结论

# 任务2：基于任务1组件实现的裂解价差交易策略研究任务

## 1. 研究目标

开发基于机器学习模型的裂解价差交易策略，包括数据获取、特征工程、模型训练、信号生成、回测验证和绩效分析全流程。

## 2. 数据需求

### 2.1 主要数据源

**期货价格数据**

- WTI原油期货（CL）
- RBOB汽油期货（RB）
- 超低硫柴油期货（HO）
- 数据频率：日线数据（至少10年历史数据）
- 数据字段：开盘价、最高价、最低价、收盘价、成交量、持仓量

**数据获取渠道**

- Quandl
- 第三方金融数据API（如yfinance等）
- 第三方自动化抓取官方数据的库

### 2.2 预测支持数据源

**基本面数据**

- EIA原油库存报告（周度）
- API原油库存数据
- 炼油厂开工率
- 季节性需求模式数据
- 地缘政治风险指数

**宏观经济数据**

- 美元指数（DXY）
- 标普500指数
- 美国国债收益率曲线
- 制造业PMI
- 通胀数据（CPI）

**市场情绪数据**

- VIX波动率指数
- 原油期货期限结构
- 持仓报告（COT报告）
- 市场波动率指标
- EIA报告

**技术指标**

- 移动平均线（不同周期）
- RSI相对强弱指数
- MACD指标
- 布林带
- 成交量相关指标

## 3. 机器学习模型要求

### 3.1 特征工程

- 计算裂解价差（1:1, 3:2:1等不同配比）
- 价差的统计特征（滚动均值、标准差、偏度、峰度）
- 季节性特征（月份、季度效应）
- 技术指标特征
- 基本面特征工程

### 3.2 模型选择与训练

**候选模型类型**

- 梯度提升树（XGBoost, LightGBM）
- 随机森林
- 支持向量机（SVM）

**训练要求**

- 训练集/验证集/测试集划分（时间序列交叉验证）
- 超参数优化（网格搜索或贝叶斯优化）
- 特征重要性分析
- 模型性能评估指标（准确率、精确率、召回率、F1分数）

### 3.3 信号生成

- 多分类输出（做多/做空/观望）
- 概率阈值设定
- 风险控制参数集成
- 仓位大小建议

## 4. 回测系统要求

### 4.1 回测框架功能

- 模拟真实交易环境（考虑交易成本、滑点）
- 支持多种仓位管理策略
- 风险控制模块（止损、止盈）
- 交易记录完整保存

### 4.2 回测参数

- 初始资金：$1,000,000
- 交易成本：双边0.05%
- 滑点模型：基于历史波动率
- 最大持仓限制
- 杠杆限制

## 5. 绩效分析要求

### 5.1 基础绩效指标

- 年化收益率
- 夏普比率
- 最大回撤
- 索提诺比率
- 卡玛比率

### 5.2 风险评估

- 波动率分析
- VaR（在险价值）计算
- 条件VaR
- 压力测试结果
- 策略容量分析

### 5.3 策略分析

- 月度收益分布
- 胜率和盈亏比
- 收益回撤比
- 策略稳定性检验
- 与基准比较（买入持有策略等）

## 6. 输出交付物

### 6.1 研究文档

- 完整的数据处理流程说明
- 模型选择理由和训练过程
- 特征重要性分析报告
- 策略逻辑详细说明

### 6.2 可视化图表

- 裂解价差历史走势图
- 模型预测效果图
- 回测资金曲线
- 回撤分析图
- 月度收益热力图

### 6.3 代码和配置

- 完整的数据处理代码
- 模型训练和预测代码
- 回测系统代码
- 参数配置文件
